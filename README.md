ปี 3 สาขาวิศวกรรมหุ่นยนต์และระบบอัตโนมัติ **FIBO, KMUTT**
สนใจตรงจุดที่ **control theory กับ machine learning มาบรรจบกัน** — ระบบที่มีสมการฟิสิกส์รองรับ แล้วให้ policy ที่เรียนจากข้อมูลมาเสริมตรงส่วนที่โมเดลอธิบายไม่ไหว

### ทำอยู่ตอนนี้

**Physical AI**
อ่านงานสาย Vision-Language-Action และ diffusion policy · residual RL บน Isaac Lab
โจทย์ที่สนใจ: ความรู้ control ที่มีอยู่เสียบเข้ากับ policy learning ตรงไหนได้บ้าง

**Homelab บน Raspberry Pi**
ระบบที่รันจริงทุกวัน ไม่ใช่ของสาธิต — n8n orchestration, Home Assistant,
บอทบันทึกรายจ่าย, ตัวติดตามการเรียน ทุกตัวเขียนเองและดูแลเอง

### เคยทำ

**แขนกล 1 แกน — STM32** · จบ มิ.ย. 2026
นำฝ่าย programming ในทีม 6 คน — หุ่นยนต์หมุน 360° หยิบแท่งไปวางตำแหน่งเป้าหมาย
Cascade controller (position ครอบ velocity) + S-curve trajectory บน STM32G474
Kalman filter ประมาณความเร็วจาก encoder · Modbus RTU slave เชื่อมกับระบบส่วนกลาง
